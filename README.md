## 📊 Key Quality Improvement & Audit Projects

### 1. Medical Record Quality (MeReQ) Scoring & Compliance Audit
* *Objective:* Assess clinical documentation accuracy, informed consent completeness, and data compliance in a multi-specialty hospital environment.
* *Methodology:* Applied the validated MeReQ evaluation tool across clinical departments to audit patient records and flag systemic documentation gaps.
* *Impact:* Standardized audit parameters, identified recurring documentation deficiencies, and provided actionable recommendations to enhance audit readiness and NABH compliance.

### 2. Inpatient Holter Monitoring Turnaround Time (TAT) Audit
* *Objective:* Reduce report delivery delays for 24-hour Holter monitoring to align with NABH turnaround standards.
* *Methodology:* Conducted Root Cause Analysis (RCA) and mapped clinical verification workflows across front desk staff, PCAs, and doctors.
* *Impact:* Isolated key communication bottlenecks and established a streamlined protocol for rapid report verification and delivery.

### 3. Multi-Ward Patient Care Assistant (PCA) Resource Allocation Optimization
* *Objective:* Balance workload distribution and minimize task completion breaches across 39 inpatient departments.
* *Methodology:* Analyzed 5,800+ operational task transactions using data-driven workflow assessment tools.
* *Impact:* Designed a digital allocation strategy to prevent TAT breaches and ensure equitable task distribution across nursing units.
